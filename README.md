# Jiang Yu — Academic Homepage

This site uses an AcadHomepage-style Jekyll layout and GitHub Pages.

## Automatic publication updates

The publication list is synchronized automatically once per day with GitHub Actions.

Public metadata sources:
- OpenReview profile: `~Jiang_Yu8`
- Crossref works linked to ORCID: `0009-0005-2880-9009`
- OpenAlex works linked to the same ORCID

The generated publication list is stored in `_data/publications.json`.
Curated metadata in `_data/publication_overrides.json` takes precedence, so equal-contribution marks, awards, preferred venue names, links, and ordering are preserved.

GitHub Pages automatically rebuilds after the sync commits a changed publication list.

News remains curated manually because acceptance announcements and award wording are editorial information that should not be inferred automatically.
